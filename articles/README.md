# مجلد المقالات

ضع مقالاتك هنا كملفات Markdown بامتداد `.md`. اسم الملف (باللاتينية) يصبح رابط المقال.

> هذا الملف (`README.md`) للشرح فقط ولا يُعامل كمقال.

## صيغة المقال

```markdown
---
title: "عنوان المقال بالعربية"
date: 2026-10-05
category: تقنية
excerpt: "سطر أو سطران يلخصان المقال."
image: assets/images/default.svg
featured: false
---

نص المقال هنا...

## عنوان فرعي

- نقطة أولى
- نقطة ثانية

> اقتباس مميز
```

- `featured: true` يظهر المقال في الصف المميز أعلى الصفحة.
- `image` اختيارية، وإن غابت تظهر صورة افتراضية.
- زمن القراءة يُحسب تلقائيًا.
